# ThesisFlow

Academic Research & Thesis Lifecycle Management System for the Department of Computer Science and Engineering, Jahangirnagar University.

## Overview
ThesisFlow digitizes and streamlines the undergraduate thesis workflow:
- Student group registration (solo or pair)
- Supervisor capacity and preference ranking
- Deterministic priority-order greedy allocation (serial dictatorship)
- Research topic proposal and revision tracking
- Academic milestones and defence evaluation

## Tech Stack
- **Backend:** Python, Django 5.2 LTS
- **Database:** PostgreSQL
- **Frontend:** Django Templates, Bootstrap 5, Vanilla JavaScript

## Team Development Simulation
This project simulates a three-developer engineering team:
- **Dev A (Lead):** Core platform, custom user auth, allocation algorithm, CI/docs.
- **Dev B (Backend):** Academics, student profiles, thesis groups, preferences.
- **Dev C (Frontend & QA):** UI/UX templates, topics, dashboard views, seed data.
